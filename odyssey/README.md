# ΟΥΤΙΣ · 無名 — A Japanese Odyssey

一张护照照片 → 单图三维重建 → 3 分钟意识流短片（1080p / 24fps / 原创合成配乐）。
全部由代码生成：Three.js 着色器逐帧离线渲染，numpy 合成配乐，二者共用 `film/timeline.json` 这一条时间轴。

> 仓库是公开的，因此**照片、三维模型、点云和成片都不进 git**（见 `.gitignore`）。
> 这里只有管线代码；换一张照片即可重跑全部流程。

---

## 概念

荷马《奥德赛》里，奥德修斯对独眼巨人自称 **Οὖτις（“无人 / 谁也不是”）**，靠这个假名逃生；
二十年后回到伊萨卡，老乳母凭他腿上的**伤疤**认出了他。

短片把这条线移植到日本：

| 奥德赛 | 日本 | 片中 |
|---|---|---|
| 海上漂泊十年 | 浦岛太郎的竜宮城：一夜 = 地上三百年 | 三条时间线交叉剪辑（诺兰《敦刻尔克》结构） |
| 自称“无人” | 禅的「無」、道元「自己をわするる」 | 脸被吸入一笔「円相」，黑白段（《奥本海默》） |
| 冥府之行 | 黄泉 · 千本鳥居 | 无尽回廊缓慢翻转（《盗梦空间》） |
| 佩涅罗佩织了又拆 | 时间逆流 | 樱花向上飘落，粒子重组人脸（《信条》） |
| 伤疤作为身份证明 | 玉手箱 · 金継ぎ | 石像开裂，裂缝注满黄金 |
| 回到伊萨卡 | 芭蕉「旅を栖とす」 | 最后回到那张护照照片——但照片上留下了金色的疤 |

哲学主轴是**身份**：护照照片是国家对“你是谁”的回答；奥德修斯的回答是“谁也不是”；
道元的回答是“忘掉自己”；而回家时能证明你是你的，是旅途留下的伤。
片中台词「使命——それは、命を使うこと」取的是“使命”二字的字面：**把命用掉**。

## 三维重建（`model/`）

单张正面照片，流程：

1. `rectify.py` —— 从护照页透视校正裁出照片本身（丢弃手写字与页面字段）
2. `analyze.py` —— MediaPipe Face Landmarker（478 个三维关键点）、多类人像分割（头发/脸/颈/衣服）、
   Depth-Anything-V2 单目深度（左右翻转平均）
3. `build_mesh.py` ——
   - 前表面：深度图按关键点深度做仿射标定，再用薄板样条修正面部低频形状
   - 轮廓平面：锚定在耳前关键点的冠状面
   - 后脑/躯干：对轮廓解泊松方程 ∇²h = −1，取 √h 充气（圆形轮廓恰好得到球，椭圆得到椭球）
   - 轮廓带 Taubin 平滑 + 法线松弛，前后表面焊接法线，纹理图集（正面 = 照片，背面 = 由照片发色合成的发丝）
   - 输出 `bust.glb`（17.8 万顶点 / 35.4 万三角形）、`points.bin`（44.7 万点）、`facemesh.json`

**局限（直说）**：正面到 ¾ 侧是照片实测，侧面与后脑是推断出来的。
要做到真正“彻底”的三维，需要多视角：绕头一圈拍 40–60 张（或 iPhone 原深感 / Polycam 扫描），
把 `analyze.py` 换成摄影测量即可，渲染和配乐代码不用动。

## 配乐（`score/score.py`）

全部合成，无采样：怀表滴答 · 谢泼德音调 · 管风琴与笙（雅乐）融合的和声 · 太鼓与低音铜管冲击 ·
斯皮卡托弦乐 ostinato · 古筝（Karplus-Strong）· 尺八（meri/kari 滑音）· 梵钟及其倒放 ·
海、雨、雷、烟、裂纹。三种卷积混响（room / hall / cave），硬切静音由主输出门控实现。

## 复现

```bash
./setup.sh                                   # 依赖、模型、字体
python3 model/rectify.py page.jpg work "113,229 857,166 916,930 159,964"
python3 model/analyze.py work .cache/models
python3 model/build_mesh.py work .cache/models film/assets   # work/ 与 film/assets/ 均不进 git
(cd film && node still.mjs /tmp/sheet.png 960 540 15 40 84 146)   # 抽帧检查
(cd film && node render.mjs --out ../out/frames --jobs 2)        # 逐帧渲染（可断点续跑）
python3 score/score.py film/timeline.json out/score.wav
FFMPEG=$(python3 -c "import imageio_ffmpeg as f; print(f.get_ffmpeg_exe())") ./encode.sh out/frames out/score.wav out
```

实时预览：在 `film/` 下起一个静态服务器打开 `index.html`（无声，实时循环），`?t=84` 可跳到指定秒。
